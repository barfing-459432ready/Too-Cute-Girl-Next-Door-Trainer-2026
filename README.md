## 🔥 Project Overview

**This tool** is a comprehensive trainer for **The Too-Cute Girl Who Moved in Next Door**. This trainer enhances the game's relationship, exploration, economy, and progression systems. It provides control over money, affection, trust, selected inventory resources, and event progress while preserving the original point-and-click structure and branching story routes.

**Target Audience:** Adults who want a more relaxed way to experience the game's romance routes, missions, point-and-click exploration, relationship progression, and money-based activities.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

The game uses point-and-click controls for traveling around the apartment building and nearby town locations. Click a destination or interactive point to move, investigate, shop, trigger events, and access activities. Activate movement-related trainer features only after the current location has finished loading.

### Tools & Inventory

Collected items and purchased resources are used to complete requests, solve events, operate equipment, and progress the story. Use inventory features outside active conversations and confirm that the item count has updated before opening another location or starting a mission.

### World & Environment

Explore the apartment building, town, shops, mine, arcade, and other event locations. Mining can provide valuables through a falling-block puzzle, while slots, crane games, and arcade shooting challenges offer additional activities and rewards. Gifts, requests, surveillance equipment, and successful events influence relationship and route progression.

### Combat & Weapons

There is no conventional combat, equipment-based fighting, or battle system. The arcade shooting activity is a score-based mini-game and should not be treated as combat when configuring trainer options.
